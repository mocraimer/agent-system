Install How the loop works

What it never does.

  • Merge into main
  • Turn on auto-merge
  • Force-push
  • Push to a base branch
  • Run a release
  • Deploy to production
  • Run anything on a fresh installWith no approval and no grant, every dispatch is held.

It refuses these before it checks authority, so a grant written too broadly cannot cover them. One narrow merge exists: with a grant you give, the loop can merge a pull request into dev, never main.

Try it on a fresh install.

You need Node.js 22.12 or newer and one signed-in runtime. Each runtime also needs the manifest-dev plugins; the README lists what each runtime needs.

Install, build, and see the first refusal

git clone https://github.com/mocraimer/agent-system.git
cd agent-system
npm ci
npm run build
npm install -g .
agentsys init --operator you@example.com
agentsys readiness --runtime claude-local
agentsys dispatch --task first-try --repo example-org/larkspur --class ci-repair \
  --runtime claude-local --profile default --actions author-changes \
  --estimate-five-hour 1 --estimate-weekly 1 --estimate-basis operator-bound \
  --prompt "should not run"

If npm install -g . fails with a permissions error, skip it and write node dist/cli/main.js wherever a command says agentsys. readiness exits 1 and names what is missing if the runtime is not set up. The dispatch exits 1 on purpose: nothing runs without your approval.

Paste this to your coding agent

Set up agent-system by following
https://raw.githubusercontent.com/mocraimer/agent-system/main/docs/AGENT-SETUP.md
Do the numbered steps and run only the commands the guide gives.
Ask me for the operator email and for the runtimes I will use; do not choose them.
Do not approve work, create grants, dispatch work under an approval or grant, or
arm the loop. For each of those, tell me what it needs and stop. End by reporting
the result of every step.

The agent installs and checks the tool, then stops at every step that needs you. It never creates authority.
